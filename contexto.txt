Registro de cambios del bot. Esta primera entrada resume las diferencias entre el código actual y la versión que ya estaba versionada en GitHub al iniciar este registro. Las modificaciones descritas aquí son cambios locales hasta que se publiquen en el repositorio.

### Eliminado

- El consumidor de compras del backend y la reconciliación de pagos.
- Las rutas OAuth utilizadas por el login de la tienda.
- La configuración obsoleta asociada a `CLIENT_ID`.

### Modificado

- El bot queda enfocado en las recompensas de boosters; conserva RCON para entregarlas en Minecraft.
- Se mantiene el servidor HTTP para futuras integraciones y herramientas de prueba locales.
- Se actualizó el README para reflejar las funciones y variables de entorno vigentes.

## 23-10-2026 — Idempotencia y recuperación de boosters

### Agregado

- Registro de derechos de roles por origen (compra, booster y vencimiento), de modo que la expiración de una recompensa no quite el rol Diamante cuando todavía existe una compra válida.
- Persistencia de la ventana de agrupación de boosts y recuperación de temporizadores después de reiniciar el bot.
- Estado de entrega RCON guardado antes de ejecutar comandos. Un resultado ambiguo requiere verificación manual y no se reintenta automáticamente.

- Se eliminó el servicio de entrega de rangos que ya no tenía consumidores, para evitar mantener un segundo camino de asignación de roles fuera del registro de derechos.

### Modificado

- La limpieza de roles vencidos conserva su registro frente a errores temporales de Discord para poder reintentar.
- Los rangos comprados crean derechos permanentes o temporales explícitos; las mejoras reemplazan derechos de compra anteriores sin borrar recompensas de booster vigentes.
- Los reclamos de boost quedan asociados al mismo nick de Minecraft durante todos sus reintentos.
- Se agregó el comando `npm test` para ejecutar las pruebas automatizadas.

### Modificado

`README.md`:

```md
# UNLP Craft Discord Bot

Bot de Discord para gestionar recompensas de boosters. No procesa pagos, no consulta compras del backend y no ofrece el login OAuth de la tienda.

[Ver Patch Notes](./PatchNotes.MD)

## Funciones

### Recompensas por boosters

- Detecta los mensajes de boost del servidor y agrupa los boosts de cada usuario durante una ventana de 20 segundos.
- El booster reclama la recompensa con `/reclamar-boost`, indicando su nickname de Minecraft.
- Mediante RCON, entrega dinero y un grupo temporal de LuckPerms; en Discord, asigna el rol Diamante durante 30 días.
- Guarda recompensas pendientes, boosts en agrupación, derechos de roles y estados de entrega en `data/boosts.json`.
- Si una conexión RCON falla de forma ambigua, la operación queda en revisión manual y no se reenvía automáticamente para evitar duplicar recompensas.
- Reintenta retirar roles vencidos si Discord falla temporalmente.

### Vínculo de cuentas Minecraft↔Discord

- `/link` genera un código privado de un solo uso, válido durante cinco minutos. Se puede volver a usar para actualizar los roles tras cambios en LuckPerms.
- El jugador canjea el código en Minecraft con `/discord link <codigo>`; el plugin obtiene su UUID autenticado y grupos heredados de LuckPerms.
- `POST /api/minecraft/link` valida el secreto del plugin, canjea el código y guarda el vínculo en `data/account-links.json`.
- El bot asigna o retira únicamente los roles gestionados por este sincronizador, según el mapeo explícito del archivo JSON de configuración.
- El mapeo editable de grupos y roles está en [`src/config/luckperms-role-map.json`](./src/config/luckperms-role-map.json); los grupos sin rol configurado se ignoran.
- El rol de booster no se incluye en el mapeo: Discord lo asigna automáticamente cuando una persona boostea el servidor.
- El proyecto del plugin Purpur está en [`minecraft-plugin/`](./minecraft-plugin/).

El hosting debe conservar `data/` entre reinicios y ejecutar una sola instancia del bot para mantener el estado de vínculos y códigos.

## Requisitos

- Node.js 18 o superior.
- Una aplicación y un bot de Discord agregados al servidor.
- RCON habilitado en el servidor de Minecraft.
- LuckPerms instalado en Minecraft para asignar el grupo temporal de la recompensa de booster.

## Instalación y ejecución

1. Instalá las dependencias:

   ```bash
   npm install
   ```

2. Configurá las variables de entorno indicadas abajo, usando `.env` localmente o el gestor de secretos del hosting.
3. Iniciá para producción:

   ```bash
   npm start
   ```

   Para desarrollo con reinicio automático:

   ```bash
   npm run dev
   ```

El servidor HTTP escucha en `0.0.0.0` en el puerto `3000` por defecto. En un hosting con puertos asignados, configurá `PORT` con el puerto asignado al servicio del bot.

Para ejecutar las pruebas automatizadas:

```bash
npm test
```

## Variables de entorno

### Discord

| Variable | Descripción |
| --- | --- |
| `DISCORD_TOKEN` | Token del bot. |
| `GUILD_ID` | ID del servidor donde opera el bot y registra los comandos slash. |

### Minecraft / RCON

| Variable | Descripción |
| --- | --- |
| `RCON_HOST` | Host del servidor Minecraft. |
| `RCON_PORT` | Puerto RCON. |
| `RCON_PASSWORD` | Contraseña RCON. |

### Vínculo Minecraft↔Discord

| Variable | Descripción |
| --- | --- |
| `MINECRAFT_LINK_API_KEY` | Secreto compartido con el plugin; el bot lo valida en `X-Api-Key`. Debe configurarse también en `plugins/UNLPCraftLink/config.yml`. |

Generá `MINECRAFT_LINK_API_KEY` como un secreto aleatorio independiente (por ejemplo, con `node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"`), y cargá el mismo valor en el bot y el plugin. Configurá el endpoint del plugin como `https://<dominio-publico-del-bot>/api/minecraft/link`. Para cambiar los roles sincronizados, editá `src/config/luckperms-role-map.json` y reiniciá el bot.

### Opcionales

| Variable | Descripción |
| --- | --- |
| `PORT` | Puerto HTTP. Por defecto `3000`. |
| `NODE_ENV` | Configurá `production` en el hosting para desactivar las herramientas de prueba. |
| `DEV_TOOLS_KEY` | Clave opcional para la ruta local de simulación de boosts. No configurarla en producción. |

## Configuración de Discord

- Habilitá los intents de servidor y miembros (`Guilds`, `GuildMembers`) y mensajes de servidor (`GuildMessages`) en el Developer Portal.
- Dale al bot permiso para ver el servidor y administrar roles.
- Ubicá el rol del bot por encima de los roles que deba asignar o quitar.
- Configurá los IDs de roles de rangos y facultades en `src/config/luckperms-role-map.json`.
- Mantené el bot en el servidor indicado por `GUILD_ID`.
- Para el vínculo Minecraft, editá `src/config/luckperms-role-map.json`; el bot nunca asigna roles que no estén mapeados.

Los IDs de Discord son identificadores de configuración, no credenciales secretas. No publiques el token ni las contraseñas de RCON.

- `/link` y `/api/minecraft/link` vinculan cuentas y sincronizan roles mapeados desde LuckPerms.

# UNLP Craft Link (plugin Purpur)

Plugin Java mínimo para vincular un jugador de Minecraft con una cuenta de Discord usando LuckPerms. Está configurado para la instalación reportada: Purpur `26.2.build.2633-stable`, Java 25 y LuckPerms API 5.5.

## Alcance actual

- Registra `/discord link <codigo>` en el servidor.
- Solo acepta comandos de jugadores, no de consola.
- Obtiene el UUID y nick de la sesión autenticada del jugador.
- Consulta los grupos heredados de LuckPerms desde su API.
- Envía el código, UUID, nick y grupos al endpoint HTTPS configurado, usando `X-Api-Key`.
- No registra el código ni la clave en logs.

## Endpoint del bot

El bot recibe la solicitud en `POST /api/minecraft/link`. Antes de desplegar ambos componentes, configurá `MINECRAFT_LINK_API_KEY` en el entorno del bot y el mismo valor en `api-key` en el plugin. Configurá los grupos y roles permitidos en `src/config/luckperms-role-map.json` del bot.

Solicitud `POST` a la URL configurada en `link-endpoint`:

```json
{
  "code": "CODIGO_DE_UN_SOLO_USO",
  "player": {
    "uuid": "UUID_AUTENTICADO_EN_MINECRAFT",
    "name": "NickDelJugador"
  },
  "groups": ["grupo_ejemplo"]
}
```

Encabezados:

```text
Content-Type: application/json
X-Api-Key: <secreto compartido>
```

El endpoint valida la clave y el código, comprueba su vencimiento y uso único, y vincula el UUID con el usuario de Discord que generó el código. Los grupos sin rol configurado en el archivo de mapeo no otorgan roles. Un error al sincronizar roles devuelve un estado no exitoso; el plugin puede reintentar la solicitud sin crear un segundo vínculo.

Al primer inicio se crea `plugins/UNLPCraftLink/config.yml`. Configurá:

- `link-endpoint`: URL HTTPS pública del endpoint del bot, no la URL de la tienda ni SFTP.
- `api-key`: mismo secreto interno que valide el endpoint del bot. Guardalo solo en el servidor; nunca lo subas a Git.
- `request-timeout-seconds`: tiempo máximo de espera HTTP.

La URL debe apuntar al dominio HTTPS público del bot, por ejemplo `https://bot.example.com/api/minecraft/link`. No uses la URL de la tienda ni una dirección SFTP.

```java
package pro.unlpcraft.link;

import java.net.URI;
import java.net.http.HttpClient;
import java.net.http.HttpRequest;
import java.net.http.HttpResponse;
import java.time.Duration;
import java.util.List;
import java.util.UUID;
import java.util.concurrent.CompletionException;
import java.util.logging.Level;

import net.luckperms.api.LuckPerms;
import net.luckperms.api.LuckPermsProvider;
import net.luckperms.api.model.group.Group;
import net.luckperms.api.model.user.User;
import org.bukkit.Bukkit;
import org.bukkit.command.Command;
import org.bukkit.command.CommandExecutor;
import org.bukkit.command.CommandSender;
import org.bukkit.command.PluginCommand;
import org.bukkit.entity.Player;
import org.bukkit.plugin.java.JavaPlugin;

public final class UNLPCraftLinkPlugin extends JavaPlugin implements CommandExecutor {
    private static final String LINK_USAGE = "Uso: /discord link <codigo>";
    private static final String LINK_CODE_PATTERN = "[A-Za-z0-9-]{6,128}";

    private HttpClient httpClient;
    private LuckPerms luckPerms;

    @Override
    public void onEnable() {
        saveDefaultConfig();
        httpClient = HttpClient.newBuilder()
                .connectTimeout(Duration.ofSeconds(getTimeoutSeconds()))
                .followRedirects(HttpClient.Redirect.NEVER)
                .build();
        luckPerms = LuckPermsProvider.get();

        PluginCommand discordCommand = getCommand("discord");
        if (discordCommand == null) {
            getLogger().severe("El comando discord no está declarado en plugin.yml.");
            getServer().getPluginManager().disablePlugin(this);
            return;
        }
        discordCommand.setExecutor(this);
        getLogger().info("Plugin habilitado. Comando disponible: /discord link <codigo>");
    }

    @Override
    public boolean onCommand(
            CommandSender sender,
            Command command,
            String label,
            String[] args
    ) {
        if (!(sender instanceof Player player)) {
            sender.sendMessage("Este comando solo puede usarlo un jugador.");
            return true;
        }

        if (args.length != 2 || !args[0].equalsIgnoreCase("link")) {
            player.sendMessage(LINK_USAGE);
            return true;
        }

        String code = args[1];
        if (!code.matches(LINK_CODE_PATTERN)) {
            player.sendMessage("El código no tiene un formato válido. Pedí uno nuevo desde Discord.");
            return true;
        }

        URI endpoint = getLinkEndpoint();
        String apiKey = getConfig().getString("api-key", "").trim();
        if (endpoint == null || apiKey.isEmpty() || apiKey.equals("REEMPLAZAR")) {
            player.sendMessage("La integración de vinculación todavía no está configurada.");
            return true;
        }

        UUID playerId = player.getUniqueId();
        String playerName = player.getName();
        player.sendMessage("Verificando tu cuenta y tus grupos de LuckPerms...");

        luckPerms.getUserManager().loadUser(playerId)
                .thenCompose(user -> sendLinkRequest(endpoint, apiKey, code, playerId, playerName, user))
                .whenComplete((response, error) -> Bukkit.getScheduler().runTask(this, () -> {
                    if (!player.isOnline()) {
                        return;
                    }
                    if (error != null) {
                        Throwable cause = error instanceof CompletionException && error.getCause() != null
                                ? error.getCause()
                                : error;
                        getLogger().log(Level.WARNING, "Falló la solicitud de vinculación de Minecraft.", cause);
                        player.sendMessage("No se pudo completar la vinculación. Probá de nuevo más tarde.");
                        return;
                    }

                    if (response.statusCode() >= 200 && response.statusCode() < 300) {
                        player.sendMessage("¡Cuenta vinculada! Ya podés cerrar este mensaje.");
                    } else if (response.statusCode() == 400 || response.statusCode() == 401
                            || response.statusCode() == 403 || response.statusCode() == 409) {
                        player.sendMessage("No se pudo vincular. Revisá que el código sea válido y no haya vencido.");
                    } else {
                        getLogger().warning("El endpoint de vinculación respondió HTTP " + response.statusCode() + ".");
                        player.sendMessage("El servicio de vinculación no está disponible. Probá más tarde.");
                    }
                }));
        return true;
    }

    private java.util.concurrent.CompletionStage<HttpResponse<String>> sendLinkRequest(
            URI endpoint,
            String apiKey,
            String code,
            UUID playerId,
            String playerName,
            User user
    ) {
        List<String> groups = user.getInheritedGroups(user.getQueryOptions()).stream()
                .map(Group::getName)
                .distinct()
                .sorted()
                .toList();

        String body = """
                {
                  "code": "%s",
                  "player": {
                    "uuid": "%s",
                    "name": "%s"
                  },
                  "groups": [%s]
                }
                """.formatted(
                escapeJson(code),
                playerId,
                escapeJson(playerName),
                groups.stream().map(group -> "\"" + escapeJson(group) + "\"")
                        .reduce((left, right) -> left + ", " + right)
                        .orElse("")
        );

        HttpRequest request = HttpRequest.newBuilder(endpoint)
                .timeout(Duration.ofSeconds(getTimeoutSeconds()))
                .header("Accept", "application/json")
                .header("Content-Type", "application/json; charset=utf-8")
                .header("X-Api-Key", apiKey)
                .POST(HttpRequest.BodyPublishers.ofString(body))
                .build();

        return httpClient.sendAsync(request, HttpResponse.BodyHandlers.ofString());
    }

    private URI getLinkEndpoint() {
        String configured = getConfig().getString("link-endpoint", "").trim();
        try {
            URI uri = URI.create(configured);
            if (!"https".equalsIgnoreCase(uri.getScheme())
                    || uri.getHost() == null
                    || uri.getUserInfo() != null
                    || uri.getFragment() != null) {
                throw new IllegalArgumentException("El endpoint debe ser una URL HTTPS pública.");
            }
            return uri;
        } catch (IllegalArgumentException error) {
            getLogger().warning("Configuración link-endpoint inválida; se requiere una URL HTTPS.");
            return null;
        }
    }

    private int getTimeoutSeconds() {
        return Math.max(1, Math.min(60, getConfig().getInt("request-timeout-seconds", 10)));
    }

    private static String escapeJson(String value) {
        StringBuilder escaped = new StringBuilder(value.length() + 16);
        for (int index = 0; index < value.length(); index++) {
            char character = value.charAt(index);
            switch (character) {
                case '"' -> escaped.append("\\\"");
                case '\\' -> escaped.append("\\\\");
                case '\b' -> escaped.append("\\b");
                case '\f' -> escaped.append("\\f");
                case '\n' -> escaped.append("\\n");
                case '\r' -> escaped.append("\\r");
                case '\t' -> escaped.append("\\t");
                default -> {
                    if (character < 0x20) {
                        escaped.append("\\u%04x".formatted((int) character));
                    } else {
                        escaped.append(character);
                    }
                }
            }
        }
        return escaped.toString();
    }
}

const { MessageType } = require('discord.js');
const { db } = require('../services/store');

const SETTLEMENT_TIMEOUT_MS = 30 * 1000;

// Herramienta SOLO para pruebas locales: simula el mensaje de sistema que Discord
// publica cuando alguien boostea el server. Queda desactivada salvo que exista
// DEV_TOOLS_KEY y nunca se registra con NODE_ENV=production.
module.exports = (app, client) => {
  const key = process.env.DEV_TOOLS_KEY;
  if (!key || process.env.NODE_ENV === 'production') return;

  app.post('/dev/fake-boost', async (req, res) => {
    if (req.get('x-dev-key') !== key) return res.sendStatus(403);

    const userId = String(req.query.userId || '');
    if (!/^\d{15,25}$/.test(userId)) return res.status(400).send('userId inválido');
    const count = Number(req.query.count || 1);
    if (!Number.isInteger(count) || count < 1 || count > 2) {
      return res.status(400).send('count debe ser 1 o 2');
    }
    const mode = req.query.mode === 'single' ? 'single' : 'multi';
    const existingClaims = db.pending?.[userId] || [];
    if (existingClaims.length > 0) {
      const existingBoosts = existingClaims.reduce((total, claim) => total + claim.boosts, 0);
      return res.status(409).send(
        `Ya hay ${existingClaims.length} recompensa(s) pendiente(s), por ${existingBoosts} boost(s), para Discord ${userId}. No se creó otra para evitar duplicarla.`,
      );
    }
    if (db.boostEvents?.[userId]) {
      return res.status(409).send('Ya hay boosts agrupándose para ese usuario; esperá a que se asienten y volvé a probar.');
    }

    // El agradecimiento que el bot publicaría en el canal se muestra en consola
    const channel = {
      send: async (text) => console.log('[fake-boost] mensaje al canal:', text),
    };

    // Cada mensaje simulado tiene su propio id y fecha, como los reales de Discord.
    // Sin esto, el segundo boost parece un duplicado del primero y se descarta.
    let sequence = 0;
    const fake = (content) => {
      const now = Date.now();
      return {
        id: `${now}${String(++sequence).padStart(3, '0')}${Math.floor(Math.random() * 1000)}`,
        createdTimestamp: now,
        createdAt: new Date(now),
        type: MessageType.GuildBoost,
        system: true,
        author: { id: userId, bot: false },
        content,
        channel,
        guild: { id: process.env.GUILD_ID },
      };
    };

    if (mode === 'single') {
      // Un solo mensaje con el número de boosts en el contenido
      client.emit('messageCreate', fake(count > 1 ? String(count) : ''));
    } else {
      // Un mensaje por cada boost
      for (let i = 0; i < count; i++) client.emit('messageCreate', fake(''));
    }

    const deadline = Date.now() + SETTLEMENT_TIMEOUT_MS;
    let claim;
    while (Date.now() < deadline) {
      claim = (db.pending?.[userId] || [])[0];
      if (claim) break;
      await new Promise((resolve) => setTimeout(resolve, 100));
    }

    if (!claim) {
      return res.status(504).send(
        `Se simularon ${count} boost(s), pero el bot no creó una recompensa pendiente en ${SETTLEMENT_TIMEOUT_MS / 1000} segundos. Revisá los logs de Boost detectado y el asentamiento.`,
      );
    }
    if (claim.boosts !== count) {
      return res.status(500).send(
        `La recompensa quedó pendiente con ${claim.boosts} boost(s), pero se habían simulado ${count}. Revisá el estado antes de reclamar.`,
      );
    }

    console.log(`[fake-boost] ${count} boost(s) simulados para ${userId} (modo ${mode})`);
    res.send(`OK: recompensa de ${count} boost(s) asentada para Discord ${userId}; ya podés reclamarla.`);
  });
};

```js
const crypto = require('crypto');
const { AccountLinkError } = require('../services/accountLinks');
const accountLinks = require('../services/accountLinksStore');
const { loadRoleMap } = require('../services/luckpermsRoleMap');

const UUID_PATTERN = /^[0-9a-f]{8}-[0-9a-f]{4}-[1-8][0-9a-f]{3}-[89ab][0-9a-f]{3}-[0-9a-f]{12}$/i;
const GROUP_PATTERN = /^[A-Za-z0-9_.+-]{1,64}$/;

module.exports = (app, client, links = accountLinks, getRoleMap = loadRoleMap) => {
  app.post('/api/minecraft/link', async (req, res) => {
    const expectedKey = process.env.MINECRAFT_LINK_API_KEY;
    if (!expectedKey || !process.env.GUILD_ID) {
      return res.status(503).json({ error: 'Minecraft link endpoint is not configured.' });
    }
    if (!safeEqual(expectedKey, req.get('x-api-key') || '')) {
      return res.status(401).json({ error: 'Invalid API key.' });
    }

    const { code, player, groups } = req.body || {};
    if (
      typeof code !== 'string'
      || !/^[a-f0-9]{48}$/i.test(code)
      || !player
      || typeof player !== 'object'
      || typeof player.uuid !== 'string'
      || !UUID_PATTERN.test(player.uuid)
      || typeof player.name !== 'string'
      || !/^[A-Za-z0-9_]{3,16}$/.test(player.name)
      || !Array.isArray(groups)
      || groups.length > 100
      || groups.some((group) => typeof group !== 'string' || !GROUP_PATTERN.test(group))
    ) {
      return res.status(400).json({ error: 'Invalid link request.' });
    }

    let roleMap;
    try {
      roleMap = getRoleMap();
    } catch (error) {
      console.error('Minecraft link role mapping is invalid:', error.message);
      return res.status(503).json({ error: 'Minecraft role mapping is not configured correctly.' });
    }
    if (Object.keys(roleMap).length === 0) {
      return res.status(503).json({ error: 'Minecraft role mapping is not configured.' });
    }

    let link;
    try {
      link = links.linkPlayer({
        code,
        uuid: player.uuid.toLowerCase(),
        playerName: player.name,
        groups: [...new Set(groups)],
      });
    } catch (error) {
      if (error instanceof AccountLinkError && error.code === 'INVALID_CODE') {
        return res.status(400).json({ error: 'The link code is invalid or expired.' });
      }
      if (error instanceof AccountLinkError && error.code === 'CONFLICT') {
        return res.status(409).json({ error: error.message });
      }
      console.error('Could not persist Minecraft account link:', error.message);
      return res.status(500).json({ error: 'Could not save the account link.' });
    }

    try {
      const guild = await client.guilds.fetch(process.env.GUILD_ID);
      const member = await guild.members.fetch(link.discordUserId);
      const targetRoleIds = [...new Set(
        link.groups
          .filter((group) => Object.hasOwn(roleMap, group))
          .map((group) => roleMap[group]),
      )];
      const previousRoleIds = link.managedRoleIds || [];
      const managedRoleIds = targetRoleIds.filter(
        (roleId) => previousRoleIds.includes(roleId) || !member.roles.cache.has(roleId),
      );

      for (const roleId of targetRoleIds) {
        if (!member.roles.cache.has(roleId)) await member.roles.add(roleId);
      }
      for (const roleId of previousRoleIds) {
        if (!targetRoleIds.includes(roleId) && member.roles.cache.has(roleId)) {
          await member.roles.remove(roleId);
        }
      }

      links.updateManagedRoles(player.uuid.toLowerCase(), managedRoleIds);
      return res.status(200).json({
        ok: true,
        linked: true,
        synchronizedRoles: targetRoleIds.length,
      });
    } catch (error) {
      console.error('Minecraft link saved, but Discord role synchronization failed:', error.message);
      return res.status(503).json({ error: 'Account link saved, but Discord roles could not be synchronized. Retry the request.' });
    }
  });
};

function safeEqual(expected, presented) {
  const expectedBuffer = Buffer.from(expected, 'utf8');
  const presentedBuffer = Buffer.from(presented, 'utf8');
  return expectedBuffer.length === presentedBuffer.length
    && crypto.timingSafeEqual(expectedBuffer, presentedBuffer);
}

`src\services\accountLinks.js`:

```js
const crypto = require('crypto');
const fs = require('fs');
const path = require('path');

const DEFAULT_FILE = path.join(__dirname, '../../data/account-links.json');
const CODE_TTL_MS = 5 * 60 * 1000;

class AccountLinkError extends Error {
  constructor(code, message) {
    super(message);
    this.name = 'AccountLinkError';
    this.code = code;
  }
}

class AccountLinkStore {
  constructor(file = DEFAULT_FILE) {
    this.file = file;
    this.data = { pendingCodes: {}, linksByUuid: {} };

    try {
      this.data = { ...this.data, ...JSON.parse(fs.readFileSync(file, 'utf8')) };
    } catch (error) {
      if (error.code !== 'ENOENT') throw error;
    }
  }

  createCode(discordUserId, now = Date.now()) {
    this.cleanupExpiredCodes(now);

    for (const [hash, pending] of Object.entries(this.data.pendingCodes)) {
      if (pending.discordUserId === discordUserId) delete this.data.pendingCodes[hash];
    }

    const code = crypto.randomBytes(24).toString('hex');
    const codeHash = hashCode(code);
    this.data.pendingCodes[codeHash] = {
      discordUserId,
      expiresAt: now + CODE_TTL_MS,
    };
    this.save();
    return { code, expiresAt: now + CODE_TTL_MS };
  }

  linkPlayer({ code, uuid, playerName, groups }, now = Date.now()) {
    this.cleanupExpiredCodes(now);
    const codeHash = hashCode(code);
    const existing = this.data.linksByUuid[uuid];
    let discordUserId;

    if (existing?.lastCodeHash === codeHash) {
      discordUserId = existing.discordUserId;
    } else {
      const pending = this.data.pendingCodes[codeHash];
      if (!pending || pending.expiresAt <= now) {
        throw new AccountLinkError('INVALID_CODE', 'El código no existe o venció.');
      }

      discordUserId = pending.discordUserId;
      const discordLink = Object.entries(this.data.linksByUuid)
        .find(([linkedUuid, link]) => link.discordUserId === discordUserId && linkedUuid !== uuid);
      if (discordLink) {
        throw new AccountLinkError('CONFLICT', 'La cuenta de Discord ya está vinculada a otro jugador.');
      }
      if (existing && existing.discordUserId !== discordUserId) {
        throw new AccountLinkError('CONFLICT', 'Este jugador ya está vinculado a otra cuenta de Discord.');
      }
      delete this.data.pendingCodes[codeHash];
    }

    const link = {
      discordUserId,
      playerName,
      groups,
      managedRoleIds: existing?.managedRoleIds || [],
      lastCodeHash: codeHash,
      linkedAt: existing?.linkedAt || now,
      updatedAt: now,
    };
    this.data.linksByUuid[uuid] = link;
    this.save();
    return { uuid, ...link };
  }

  updateManagedRoles(uuid, roleIds) {
    const link = this.data.linksByUuid[uuid];
    if (!link) throw new AccountLinkError('NOT_LINKED', 'El jugador no está vinculado.');
    link.managedRoleIds = [...new Set(roleIds)];
    link.updatedAt = Date.now();
    this.save();
  }

  cleanupExpiredCodes(now = Date.now()) {
    let changed = false;
    for (const [hash, pending] of Object.entries(this.data.pendingCodes)) {
      if (pending.expiresAt <= now) {
        delete this.data.pendingCodes[hash];
        changed = true;
      }
    }
    if (changed) this.save();
  }

  save() {
    fs.mkdirSync(path.dirname(this.file), { recursive: true });
    const temporaryFile = `${this.file}.tmp`;
    fs.writeFileSync(temporaryFile, JSON.stringify(this.data, null, 2));
    fs.renameSync(temporaryFile, this.file);
  }
}

function hashCode(code) {
  return crypto.createHash('sha256').update(code).digest('hex');
}

function recordBoost(db, userId, count, channelId, settleAt) {
  db.boostEvents ||= {};
  const current = db.boostEvents[userId] || { count: 0 };
  const event = {
    count: current.count + count,
    channelId,
    settleAt,
  };
  db.boostEvents[userId] = event;
  return event;
}

function settleBoost(db, userId, now, claimId) {
  const event = db.boostEvents?.[userId];
  if (!event || event.settleAt > now) return null;

  delete db.boostEvents[userId];
  db.pending[userId] ||= [];
  const claim = {
    id: claimId,
    boosts: Math.min(event.count, 2),
    createdAt: now,
  };
  db.pending[userId].push(claim);
  return { claim, channelId: event.channelId };
}

function scheduleSettlement(userId, client) {
  clearTimeout(timers.get(userId));
  const event = db.boostEvents[userId];
  if (!event) {
    timers.delete(userId);
    return;
  }

  const delay = Math.max(0, event.settleAt - Date.now());
  const timer = setTimeout(async () => {
    timers.delete(userId);

      await settlePendingBoost(userId, client);
      scheduleSettlement(userId, client);
    } catch (error) {
      console.error('No se pudo asentar el boost; se reintentará:', error.message);
      scheduleSettlement(userId, client);
    }
  }, delay);
  timers.set(userId, timer);
}

  console.log('Boost detectado:', userId, 'content:', JSON.stringify(message.content));
}

    scheduleSettlement(userId, client);

async function settlePendingBoost(userId, client) {
    const previousEvent = db.boostEvents[userId] && { ...db.boostEvents[userId] };
    const settled = settleBoost(db, userId, Date.now(), crypto.randomUUID());
    if (!settled) return false;
    try {
        save();
    } catch (error) {
        db.boostEvents[userId] = previousEvent;
        db.pending[userId] = db.pending[userId].filter((claim) => claim.id !== settled.claim.id);
        if (db.pending[userId].length === 0) delete db.pending[userId];
        throw error;
    }

    if (settled.channelId) {
        try {
            const channel = await client.channels.fetch(settled.channelId);
            await channel.send(`¡Gracias por el boost, <@${userId}>! Usá \`/reclamar-boost\` con tu nick de Minecraft para recibir tu recompensa.`);
        } catch (error) {
            console.error('No se pudo notificar el boost asentado:', error.message);
        }
    }
    return true;
}

async function claimBoost(member, nick) {
    if (!NICK_RE.test(nick)) return { msg: 'Nickname inválido.' };
    const claim = (db.pending[member.id] || [])[0];
    if (!claim) return { msg: 'No tenés recompensas de boost pendientes.' };
    if (busy.has(member.id)) return { msg: 'Tu reclamo ya se está procesando.' };

    const reward = REWARDS[claim.boosts];
    if (!reward) throw new Error(`No hay recompensa configurada para ${claim.boosts} boost(s).`);
    const rank = RANKS[reward.rank];
    if (!rank) throw new Error(`El rango de booster "${reward.rank}" no está configurado.`);
    busy.add(member.id);
    try {
        if (claim.minecraftNick && claim.minecraftNick !== nick) {
            return { msg: `Este reclamo ya está asociado al nick ${claim.minecraftNick}. Usá ese mismo nick para continuar.` };
        }
        claim.minecraftNick ||= nick;
        claim.id ||= crypto.randomUUID();
        if (claim.moneyGiven && !claim.moneyDelivery) claim.moneyDelivery = 'done';
        if (claim.rankGiven && !claim.rankDelivery) claim.rankDelivery = 'done';
        if (claim.tagGiven && !claim.tagDelivery) claim.tagDelivery = 'done';
        save();

        try {
            await deliverOnce(
                claim,
                'moneyDelivery',
                `eco give ${claim.minecraftNick} ${reward.money}`,
                (command) => mc.run(command, 0),
                save,
            );
            await deliverOnce(
                claim,
                'rankDelivery',
                `lp user ${claim.minecraftNick} parent addtemp ${reward.minecraftGroup} ${reward.days}d accumulate`,
                (command) => mc.run(command, 0),
                save,
            );
            if (reward.tagPermission) {
                await deliverOnce(
                    claim,
                    'tagDelivery',
                    `lp user ${claim.minecraftNick} permission settemp ${reward.tagPermission} true ${reward.days}d accumulate`,
                    (command) => mc.run(command, 0),
                    save,
                );
            }
        } catch (error) {
            if (error.manualReview) {
                console.error('Entrega de recompensa en revisión manual:', error.cause?.message || error.message);
                return {
                    msg: `La entrega de ${rank.title} requiere revisión manual. No vuelvas a reclamarla hasta verificar el estado en Minecraft.`,
                };
            }
            throw error;
        }

        const grantId = `booster:${claim.id}`;
        const existingExpiration = getGrantExpiration(member.id, rank.discordRoleId, grantId);
        const expiresAt = existingExpiration
            ?? Math.max(Date.now(), getLatestExpiration(member.id, rank.discordRoleId, 'booster')) + reward.days * DAY;
        await grantRole(member, {
            userId: member.id,
            roleId: rank.discordRoleId,
            grantId,
            source: 'booster',
            expiresAt,
        });

        db.pending[member.id].shift();
        save();
    } catch (e) {
        console.error(e);
        return { msg: 'No se pudo entregar ahora, probá de nuevo en un rato.' };
    } finally {
        busy.delete(member.id);
    }

    return {
        msg: `¡Listo! Recibiste $${reward.money.toLocaleString('es-AR')} y el rango ${rank.title} por ${reward.days} días en ${nick}.`,
    };
}

function startExpiryJob(client) {
    let running = false;
    const tick = async () => {
        if (running) return;
        running = true;

            await reconcileExpiredRoles(client);
        } catch (error) {

            running = false;

async function deliverOnce(record, statusKey, command, send, save) {
  const status = record[statusKey];
  if (status === 'done') return;
  if (status) {
    const error = new Error('Esta entrega requiere revisión manual para evitar duplicarla.');
    error.manualReview = true;
    throw error;
  }

  record[statusKey] = 'processing';
  save();

  try {
    await send(command);
  } catch (cause) {
    record[statusKey] = 'manual_review';
    save();
    const error = new Error('RCON no confirmó la entrega. Revisá el estado en Minecraft antes de modificarla.');
    error.manualReview = true;
    error.cause = cause;
    throw error;
  }

  record[statusKey] = 'done';
  save();
}

function withRoleLock(userId, roleId, operation) {
  const key = `${userId}:${roleId}`;
  const previous = roleQueues.get(key) || Promise.resolve();
  const current = previous.catch(() => {}).then(operation);
  roleQueues.set(key, current);
  return current.finally(() => {
    if (roleQueues.get(key) === current) roleQueues.delete(key);
  });
}

async function grantRole(member, { userId, roleId, grantId, source, expiresAt = null }) {
  return withRoleLock(userId, roleId, async () => {
    const existingGrants = getGrants(db, userId, roleId);
    let changed = false;

    if (expiresAt !== null && member.roles.cache.has(roleId) && Object.keys(existingGrants).length === 0) {
      changed = addGrant(db, userId, roleId, 'legacy:existing-role', 'permanent') || changed;
    }

    changed = addGrant(db, userId, roleId, grantId, source, expiresAt) || changed;
    if (changed) save();
    if (!member.roles.cache.has(roleId)) await member.roles.add(roleId);
  });
}

async function supersedeRole(member, userId, roleId) {
  return withRoleLock(userId, roleId, async () => {
    const result = supersedeNonBoosterGrants(db, userId, roleId);
    if (result.hasActive) {
      if (result.changed) save();
      return;
    }

    if (member.roles.cache.has(roleId)) await member.roles.remove(roleId);
    const deleted = deleteRoleGrants(db, userId, roleId);
    if (result.changed || deleted) save();
  });
}

async function reconcileExpiredRoles(client) {
  const guild = await client.guilds.fetch(process.env.GUILD_ID);

    for (const [roleId] of Object.entries(userRoles)) {

        const hasExpired = Object.values(grants)
          .some((grant) => grant.expiresAt !== null && grant.expiresAt <= Date.now());
        if (!hasExpired) return;

        if (hasActiveGrant(db, userId, roleId)) {

        let member;
        try {
          member = await guild.members.fetch(userId);
        } catch (error) {
          if (error.code === 10007 || error.code === 10013) {
            deleteRoleGrants(db, userId, roleId);
            save();
            return;
          }
          console.error(`[Expiración] No se pudo consultar el miembro ${userId}; se reintentará:`, error.message);
          return;
        }

        if (hasActiveGrant(db, userId, roleId)) {
          pruneExpiredGrants(db, userId, roleId);
          save();
          return;
        }

        try {
          if (member.roles.cache.has(roleId)) await member.roles.remove(roleId);
        } catch (error) {
          console.error(`[Expiración] No se pudo quitar el rol ${roleId}; se reintentará:`, error.message);
          return;
        }
        deleteRoleGrants(db, userId, roleId);
        save();
      });
    }
  }

function ensureLedger(db) {
  db.roleEntitlements ||= {};
  db.roles ||= {};
  let changed = false;

  for (const [legacyKey, role] of Object.entries(db.roles)) {
    if (!role || typeof role !== 'object' || !Number.isFinite(Number(role.expiresAt))) continue;

    const separator = legacyKey.indexOf(':');
    const userId = role.userId || (separator === -1 ? legacyKey : legacyKey.slice(0, separator));
    const roleId = role.roleId || (separator === -1 ? null : legacyKey.slice(separator + 1));
    if (!userId || !roleId) continue;

    const source = role.userId ? 'purchase' : 'booster';
    addGrant(db, userId, roleId, `legacy:${legacyKey}`, source, Number(role.expiresAt));
    delete db.roles[legacyKey];
    changed = true;
  }

  return changed;
}

function getGrants(db, userId, roleId) {
  return db.roleEntitlements?.[userId]?.[roleId]?.grants || {};
}

function getGrant(db, userId, roleId, grantId) {
  return getGrants(db, userId, roleId)[grantId];
}

function addGrant(db, userId, roleId, grantId, source, expiresAt = null) {
  db.roleEntitlements ||= {};
  const userGrants = db.roleEntitlements[userId] ||= {};
  const roleEntry = userGrants[roleId] ||= { grants: {} };
  if (roleEntry.grants[grantId]) return false;
  roleEntry.grants[grantId] = { source, expiresAt };
  return true;
}

function latestExpiry(db, userId, roleId, source, now = Date.now()) {
  return Object.values(getGrants(db, userId, roleId))
    .filter((grant) => grant.source === source && grant.expiresAt > now)
    .reduce((latest, grant) => Math.max(latest, grant.expiresAt), now);
}

function hasActiveGrant(db, userId, roleId, now = Date.now()) {
  return Object.values(getGrants(db, userId, roleId))
    .some((grant) => grant.expiresAt === null || grant.expiresAt > now);
}

function removeExpiredGrants(db, userId, roleId, now = Date.now()) {
  const grants = getGrants(db, userId, roleId);
  let changed = false;
  for (const [grantId, grant] of Object.entries(grants)) {
    if (grant.expiresAt !== null && grant.expiresAt <= now) {
      delete grants[grantId];
      changed = true;
    }
  }
  return { changed, hasActive: hasActiveGrant(db, userId, roleId, now) };
}

function pruneExpiredGrants(db, userId, roleId, now = Date.now()) {
  const grants = getGrants(db, userId, roleId);
  let changed = false;
  for (const [grantId, grant] of Object.entries(grants)) {
    if (grant.expiresAt !== null && grant.expiresAt <= now) {
      delete grants[grantId];
      changed = true;
    }
  }
  return changed;
}

function supersedeNonBoosterGrants(db, userId, roleId, now = Date.now()) {
  const grants = getGrants(db, userId, roleId);
  let changed = false;
  for (const [grantId, grant] of Object.entries(grants)) {
    if (grant.source !== 'booster') {
      delete grants[grantId];
      changed = true;
    } else if (grant.expiresAt !== null && grant.expiresAt <= now) {
      delete grants[grantId];
      changed = true;
    }
  }
  return { changed, hasActive: hasActiveGrant(db, userId, roleId, now) };
}

function deleteRoleGrants(db, userId, roleId) {
  const userGrants = db.roleEntitlements?.[userId];
  if (!userGrants || !userGrants[roleId]) return false;
  delete userGrants[roleId];
  if (Object.keys(userGrants).length === 0) delete db.roleEntitlements[userId];
  return true;
}

        this.body = value;

    };
